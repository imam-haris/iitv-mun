# IIT (BHU) MUN Website

A modern, responsive, and high-performance web platform built for the IIT (BHU) Model United Nations conference. The website provides delegates with seamless access to committees, agendas, event timelines, and registration, all through a smooth and interactive user experience.

---

##  Features

* Fully responsive design (mobile + desktop)
* Interactive UI with smooth animations
* Committee and agenda showcase
* Event timeline and schedule
* Delegate registration system
* Fast performance with optimized builds
* Clean and scalable architecture

---

##  Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/imam-haris/iitv-mun.git
cd iitv-mun
```

### 2. Install dependencies

```
npm install
```

### 3. Run development server

```
npm run dev
```

App will run on:

```
http://localhost:5173
```

---

##  Build for Production

```
npm run build
```

### Preview production build

```
npm run preview
```
